SetUnion
--------

Worst case complexity: n+m

Explanation: I go through both s1 and s2, then use created insert function to put all elements
from s1 and s2 to a new set. The insert function will automatically check if any elements from 
s1 is already in s2. Therefore there is no worries about the sets s1 and s2 have the same elements
and put this element into new set twice.

O It should go through both Sets s1 and s2, so time complexities should be n+m.
